指令参考

在 GUI 输入 / 或打开“/ 指令说明”，可以搜索并选择指令。任务操作需要先选中任务；步骤按当前对话审批模式推进；平衡模式下覆盖和代码执行仍需确认，自主执行需用户明确授权。

指令 用途 支持范围与说明
/library 资料库 CLI：CLI：/library add 文件路径、search 问题、list、mount ID、unmount ID、remove ID；GUI 使用侧栏资料库。
/memory 会话记忆 CLI：CLI：/memory [检索词] 查看当前对话的摘要、预算和相关记忆。
/expert 专家模式 CLI：CLI：/expert list、use ID、off、show、status、import JSON路径、remove ID；GUI 使用侧栏专家模式。
/autonomy 审批模式 CLI：CLI：/autonomy strict
/term 持续终端 CLI：CLI：/term open 目录，/term agent ID 目标；支持 send/read/approve/interrupt/close/trust/revoke。
/终端 终端与 Agent GUI：在指定目录打开持续 PowerShell，直接输入命令或交给 Agent 连续工作；也支持单次审批。
/terminal CLI 终端 CLI：CLI 用法：/terminal {"cwd":"绝对目录","command":"命令","timeout_seconds":60}；再 /tool-approve 编号。
/聊天 普通对话 GUI：直接对话，按需搜索公开资料；复杂执行可确认创建任务，历史与 CLI 共用。
/任务模式 任务模式 GUI：自动选择能力；按权限执行低风险步骤，覆盖文件和代码执行需要确认。
/新建 创建新会话 GUI：新建一个独立会话，挂载设置独立保存。
/任务 查看任务 GUI：查看当前会话的任务，点击卡片选择操作对象。
/状态 查看进度 GUI：展示所选任务步骤和状态。
/结果 查看结果 GUI：展示所选任务保存的结果与摘要校验。
/继续 审阅代码 GUI：打开当前 Python 步骤代码预览，仍需输入 EXECUTE。
/暂停 暂停任务 GUI：确认后阻止启动后续步骤，在途调用可能完成。
/恢复 解除暂停 GUI：确认解除暂停，不会自动执行代码。
/取消任务 取消任务 GUI：确认取消，已产生的外部效果不保证撤销。
/技能 技能与挂载 GUI：查看本地技能内容，选择新任务的指导技能。
/工具 工具库 GUI：查看自动选择的可信工具；在权限设置中禁用工具。
/agent 自动任务 CLI：CLI 用法：/agent 目标；自动规划并推进允许的步骤。
/tool-approve 确认工具步骤 CLI：CLI 用法：/tool-approve 任务序号；查看参数并确认。
/mcp-tools MCP 服务发现 CLI：CLI 用法：/mcp-tools [配置文件]；连接标准 MCP 并列出工具。
/tool-modes 查看工具权限 CLI：CLI 查看与 GUI 共用的工具策略和工作目录。
/tool-mode 设置工具权限 CLI：CLI 用法：/tool-mode 工具名 auto
/帮助 指令说明 GUI：查看全部指令及其支持范围。
/允许 审批文件读取 GUI：预览当前步骤的工具与准确文件路径，确认后读取一次。
/拒绝 拒绝步骤 CLI：在 CLI 拒绝当前步骤。
/重规划 重规划 CLI：在 CLI 起草当前任务的新计划并查看差异。
/确认 确认重规划 CLI：在 CLI 确认已审阅的重规划。
/取消 取消重规划 CLI：在 CLI 取消重规划草案。
/诊断 恢复诊断 CLI：在 CLI 核对检查点及结果证据。
/失败 失败分类 CLI：在 CLI 查看失败事件及诊断。
/tool-contracts 工具连接检查 CLI：在 CLI 连接 MCP 并核对契约。
/help advanced 高级指令 CLI：在 CLI 查看兼容与开发者指令。

CLI 兼容命令

CLI 的 /help advanced 列出高级与兼容命令。以下为现有帮助原文，GUI 不将其转换为任意终端命令。

兼容及开发者命令（高级）
/multi /multi-status /multi-approve /multi-deny
/flow-code /flow-status /flow-approve /flow-deny
/auto on|off /auto-status
/code-propose /code-approve /code-deny /code-status
/permissions /permit /deny-read /allow-read /revoke-read
/skills /agent-step-run /agent-step-approve /agent-step-result
/step-run /step-approve /step-result
/plan-new /plans /plan /plan-approve /plan-reject
/task-new /tasks /task /step /task-events /task-cancel
/new /use /sessions /runs /events /status /interrupted /resume /approve-resume

高级恢复与重规划以 CLI 预览提示为准。GUI 支持文件与工具审批；技能挂载不授予执行权限。当前对话的审批模式优先于旧帮助中逐步确认的默认描述，工具禁用始终优先。
