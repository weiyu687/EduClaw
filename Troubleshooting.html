常见问题

页面提示凭据或来源无效

使用终端本次启动输出的地址。重启后旧凭据失效。不要将地址从 127.0.0.1 改成其他主机名，也不要用其他来源的页面代理 API。

任务输入不可用

先新建或选择会话。提交前至少挂载一个支持规划的工具，并保存修改。新会话默认不挂载任何能力。

挂载了工具但不能规划

检查工具卡片是否标注“当前规划器暂不支持”。规划器只接受已支持的读取工具和 Python 代码步骤；挂载不会扩展其步骤协议。

规划失败

核对本机模型变量、网络和目标是否能由已挂载工具完成。模型输出未知工具、未指定路径、无效代码或超限计划都会失败。错误消息隐藏模型供应商的原始异常以避免暴露敏感信息。

服务重启导致规划中断时先检查任务列表；系统不会自动重试，防止重复生成任务。

Python 执行失败

确认 Docker 可用、python:3.10-slim 镜像存在，以及 MCP 能启动。CLI 的 /失败 与 /诊断 可查看原因。执行已经认领而结果不确定时不要删除认领记录重跑；先核查保存结果和外部效果。

文件任务停在待授权

这是当前 GUI 的能力边界。通过 CLI 切换到同一会话，选择任务，使用 /允许 查看并确认准确文件范围；之后的 Python 步骤可回到 GUI 审阅。

Wiki 与网站不同步

两处均从 docs/wiki 构建。修改 Markdown 后重新构建并发布两个目标。GitHub Pages 部署需要时间；以远端分支提交和 Pages 构建状态为准。

提交超时或重复点击

同一提交标识在服务端去重。先查看最近提交和任务列表。规划、代码执行和生命周期操作都有独立状态，不应靠重复点击来恢复未知结果。
