# 数据质量核查

先用 profile_csv 获取行数、空值、完全重复行和数值统计；它不识别业务主键重复，需按用户给定主键继续核查。
extract_json 和 extract_jsonl 拒绝重复键、非有限数及超限输入；不要把失败解释为空数据。
将问题计数和问题样本分开，保留明确的原始行号或业务标识，不擅自修复、丢弃或覆盖源文件。
数值统计为十进制字符串；科学计数法不参与 profile_csv 数值统计，必须显式说明。
需要业务一致性校验时先展示完整 Python 代码，再执行。跨步骤引用保存的结果，不能通过 Python 重新读取本地文件。
最终列出已检查维度、未检查维度、异常数量与可行动的修复建议。
