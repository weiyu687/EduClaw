# 学习进度分析

推荐工具：extract_csv、extract_json、extract_jsonl、extract_text、profile_csv、run_python_code。

以用户明确提供的 CSV 成绩表、JSON 评分规则、JSONL 出勤事件和文本课程说明为输入。
先验证学生或样本主键唯一性、缺失值、分数范围与未知 ID，再关联数据。
评分权重、达标线和出勤规则必须来自用户指定文件，不自行发明。
将标准化成绩、按 ID 的出勤统计、汇总反馈分成独立步骤，后续消费不可变 JSON 结果。
最终输出数据质量检查、汇总统计、需要关注的样本及证据来源；不要自动作出录取、处分或其他高影响决定。
不要在分析日志里额外写入不必要的个人信息。每次执行仍需准确代码审批。
