---
name: Product Planning
description: Turn a user need into a scoped delivery plan with acceptance checks and tradeoffs.
version: 1.0
---

Use this skill for product design or feature planning.

1. Identify the user, their current workflow, and the failure or unmet need.
2. Define observable success and the smallest complete user flow.
3. Compare practical options using effort, reversibility, accessibility, and maintenance cost.
4. List implementation stages with an acceptance check after each stage.
5. Record assumptions and decisions that still require user input.

Keep planning separate from claims of completed implementation.
