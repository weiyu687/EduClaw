# GUI 使用指南

## 普通多轮对话

新建对话后默认进入“普通对话”，无需挂载工具。输入消息并发送，可以继续追问；历史保存在本地，刷新后恢复。回复过程中显示“正在回复”，同一对话一次只处理一条消息。普通对话不调用工具，也不会把消息自动规划成任务。

GUI 与 CLI 使用相同的普通对话历史。CLI 输入 `/聊天` 进入普通对话模式，`/任务模式` 返回任务路由；`/chat 消息内容` 可发起单轮普通对话，`/history` 或 `/对话记录` 查看历史。用 `/use` 切换到同一会话后可以接着追问。模型上下文使用最近 24 轮普通对话，旧版工具 Agent 的检查点历史不自动混入普通对话。

## 名称、重命名和删除

首条消息先生成简短临时名称，回复完成后使用模型概括的主题标题；手动名称不会被自动覆盖。左侧“重命名”修改当前会话名称，与 CLI `/rename-session 名称` 双向同步。

左侧“删除对话”先展示影响，再确认删除，与 CLI `/delete-session`、`/delete-confirm` 共用软删除机制。删除后两端列表都隐藏该会话，不能继续使用；历史审计不会物理清除。正在回复或存在未结束任务时，需先完成或取消后再删除。

## 创建第一个任务

1. 点击“＋ 新建对话”，切换到“任务模式”。
2. 直接描述目标，例如“搜索 machine learning 的公开资料，保存到工作目录的 research.md，再读回核对”。无需勾选工具。
3. “最近提交”显示规划进度，点击“查看任务”查看每一步和结果证据。
4. 搜索、工作目录内读取和新建文本默认自动执行。已有文件覆盖会暂停，点击“审批工具操作”，核对原内容及新内容后确认。
5. Python 仍需“审阅并执行”，核对代码并输入 `EXECUTE`。

最多两项规划同时进行，每个计划最多 12 步。模型规划期限为 75 秒，单次自动执行进程最多 240 秒。失败或中断不自动重试；先核对结果再决定下一步。普通对话保持不调用工具。

## 技能偏好与工具目录

技能卡片可以展开阅读完整指导内容；超长内容在界面截断并提示。工具卡片显示说明、版本、风险类型、规划支持情况、输入和输出 Schema。

技能勾选后点击“保存挂载”才会生效。取消勾选并保存可移除手动偏好；系统仍会按任务需要选择适合的技能。配置按会话保存，刷新后保留，不影响其他会话。

每次提交保存一份当时的挂载快照。后续更改配置只影响新任务，不会改写已经生成的计划。技能内容不能授予权限，工具可用也不等于代码或路径授权。已有任务若不应继续，应通过暂停或取消操作处理。

## 输入指令

输入 `/` 可筛选指令，点击条目选择；也可打开“/ 指令说明”搜索用途。标有 GUI 的指令会切换视图或打开确认窗口，标有 CLI 的指令显示用法说明，不会偷偷运行终端命令。

执行、暂停、恢复和取消必须先在任务列表中选择明确的任务。`/继续` 只是打开代码预览，不能替代 `EXECUTE`。

## 查看状态与控制执行

- 刷新页面只读取状态，不自动重发审批。
- 任务详情每 3 秒同步，最近提交每 2 秒同步。
- 暂停阻止后续步骤启动；在途步骤可能完成。
- 恢复暂停不会启动工具，也不会自动授予权限。
- 取消会发出持久取消请求；已有外部效果不保证可撤销。
- 关闭页面不会取消已提交的工具执行。

同一提交标识重复发送会返回原提交记录。网络超时后先查看“最近提交”和任务列表，避免把同一目标主动作为新任务提交。

重规划和证据修复仍需 [CLI 指令](Commands)。新闻任务会基于已保存的来源生成摘要；其他任务仍查看工具结果。


## 待审批在哪里确认？

先点击“查看任务”或任务卡片。当前文件步骤显示“审批文件读取”，点击后核对工具和完整路径，再点击“确认审批文件读取”。Python 步骤点击“审阅并执行”，核对代码并输入 EXECUTE。确认后按既有权限继续低风险步骤；覆盖文件和执行代码仍会再次暂停。搜索与写入步骤使用“审批工具操作”。

## 左侧栏与权限管理

左侧提供新建对话、历史对话、技能管理、工具管理、工具与文件权限、指令说明。会话选择与新建对话也在左侧；中央保留任务输入、审批和结果。

“工具与文件权限”可选择“自动（限定范围）”“每步确认”或“禁用”，设置适用于当前数据目录的所有会话，包括 CLI。恢复策略不是无条件允许；未知工具、代码和文件仍受到原有策略约束。禁用会在调用网关处阻止工具，已经启动的调用无法撤回。

文件授权输入本机绝对路径，选择“仅一次读取”或“当前对话”，预览规范路径和范围后确认。文件夹授权包含子目录；仅允许读取。列表支持撤销授权，已使用的单次授权会标记。GUI 不新增持久跨会话授权，但可以查看和撤销 CLI 已创建的持久授权。任务中单次审批不留下持续文件授权。

## 审批后的步骤状态

提交确认后立即显示“已审批，准备执行”，认领并持有执行锁时显示“已审批／执行中”，完成后显示结果状态。CLI 的步骤状态使用同一个判定逻辑。若执行进程中断、认领仍在但执行锁已释放，显示“执行结果待核查”，不会退回待审批或自动重放。

## 自动工具与文件工作目录

“工具”面板是能力目录，不再要求勾选。规划器从受信任且未禁用的工具中按目标选择；技能会根据目标选择，也可保存个人偏好。旧版保存的工具勾选不再限制任务，请使用“工具与文件权限”禁用不需要的工具。

工作目录显示在权限面板，默认为所选数据目录下的 `workspace`。只有该目录内的文本、数据和静态文档可写入；不会自动覆盖已有文件。工作目录外读取仍需要路径授权，现有授权目录内的读取可以自动推进。代码永远不能设置成自动批准。

CLI 使用 `/agent 目标` 创建同类自动任务，`/tool-approve 任务编号` 审阅等待确认的步骤。`/tool-modes` 查看工作目录及策略，`/tool-mode public_search ask` 可把搜索改成每步确认。设置与 GUI 共用。

## 新闻请求

任务模式支持“给我最新的AI新闻资讯，昨天的”和“给我最近的AI新闻资讯总结”。新闻摘要直接显示在任务详情，包含北京时间范围、来源与发布时间。搜索失败、无匹配报道和摘要失败分别显示，不把百科搜索当成新闻搜索。
