## 2026-10-10：Phase 5.12.4 动态重规划增量

`/重规划 第二步增加每页表格数量` 或 `重规划 第二步增加每页表格数量` 生成草案。
旧 `/multi-replan <ID>` 会询问修改要求，带第三个参数时直接使用该修改要求。
`/确认` 展示新旧工具、参数、依赖和风险，输入 `REPLAN` 才提交；`/取消` 放弃草案。
没有实际结构变化时拒绝创建新版本。推导出的重复依赖元数据不算计划变化。

`ReplanService` 是可供未来 GUI 共用的应用服务，CLI 只负责收集输入和展示。

任务用户编号保持不变；版本链保存原任务、新任务、修改要求、计划摘要、批准者和时间。
本地批准者表示当前 CLI 会话身份，不代表已实现团队身份认证。

执行账本新增 `task_freezes` 表，冻结和执行认领通过 SQLite `BEGIN IMMEDIATE`
互斥。多个存储库之间采用不可重试的提交状态和持久冻结，不宣称存在跨库事务。
提交中断后旧任务与可能产生的新任务均保持冻结，需人工核查，不能删除记录后重试。

## 2026-10-10：Phase 5.13 失败恢复与任务控制增量

新增 `/暂停`、`/恢复`、`/取消任务`、`/诊断`、`/失败`。暂停阻止后续步骤，
正在进行的调用不因暂停而承诺回滚；取消通过持久状态通知执行入口。
恢复预览需要明确输入 `RESUME` 或 `RECOVER`，不授予读取或代码执行权限。
后续步骤仍需重新审批。`/取消` 仍表示放弃重规划草案。

`TaskLifecycle` 提供共享应用服务；执行事件区分规划、Schema、权限、工具失败、
超时、取消、未知结果和持久化错误。工具调用仅尝试一次，等待有上限并显示进度。
为兼容旧检查点，失败执行的检查点仍可显示 `uncertain`；具体原因以事件分类为准。

成功结果已经落盘、检查点尚未推进时，可校验结果摘要、参数指纹、执行账本和前序
证据后修复检查点。修复不调用工具。没有成功证据、旧操作缺少参数指纹或结果损坏时
拒绝恢复与重放。Windows 原生文件锁阻止活跃执行与恢复竞争，进程退出自动释放锁。
跨库修复使用持久冻结；修复途中再次崩溃时保留冻结，需人工核查。

客户端补发标准 MCP 取消通知，服务端同步工具在工作线程运行；内置 Docker Python
执行器响应取消并强制清理容器。其他外部工具的取消仍是请求，不能保证撤销外部副作用。
第一次真实取消验收发现 SDK 未发送通知导致容器残留，修正后重新进行完整验收。

## 2026-10-11：Phase 5.14a 工具契约与 CSV 接入

可信应用契约统一提供 MCP 描述、规划工具集合、路径参数和扩展名路由。注册表
校验 SDK 版本、Schema、结果类型和大小，适配器由应用代码显式绑定。动态发现的
元数据不安装代码，也不产生权限；输出 Schema 或版本元数据变化会使旧知悉标记
失效，已有动态权限偏好默认拒绝，需重新检查。

新增 `extract_csv`，复用原有路径审批、执行认领、不可变结果和 Python 引用流程，
不在任务执行循环新增 CSV 专用分支。读取 UTF-8/BOM CSV，保持单元格为字符串，
支持引号和多行字段，拒绝坏结构及超限输入，并逐行限制输出膨胀。
`/tool-contracts` 与“检查工具契约”共享只读服务，显示连接声明、版本和权限。
详细接入说明与示例见 [工具 SDK](TOOL_SDK.md)。

### 实测发现与修正

## 2026-10-12：GUI 第一增量（TypeScript + React）

依用户技术选择新增 `web/`，使用 TypeScript、React、Vite 和锁定的依赖清单。
界面提供会话选择、任务卡片、状态进度、步骤依赖、保存结果、摘要校验，以及
暂停、解除暂停、取消的预览确认。适配桌面和窄屏，支持键盘选择、空状态及错误提示。
工具输出作为文本显示，不渲染 HTML；完整结果超过预览上限时明确提示。

Python 本地 API 复用既有 TaskContext / TaskLifecycle / 执行账本和结果仓库。
仅绑定 127.0.0.1，使用每次启动随机 Bearer 凭据，校验 Host、Origin 和请求结构，
无 Cookie 授权和跨域开放。确认票据 120 秒有效、一次性消耗、绑定任务版本和状态；
状态变化后重新预览，错误后不自动重试操作。页面关闭不取消任务。
