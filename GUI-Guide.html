GUI 使用指南

普通多轮对话

新建对话后默认进入“普通对话”，无需挂载工具。输入消息并发送，可以继续追问；历史保存在本地，刷新后恢复。回复过程中显示“正在回复”，同一对话一次只处理一条消息。普通对话可以按需调用公开资料搜索，直接返回带来源的回答；不会自动创建文件或执行代码。

GUI 与 CLI 使用相同的普通对话历史。CLI 输入 /聊天 进入普通对话模式，/任务模式 返回任务路由；/chat 消息内容 可发起单轮普通对话，/history 或 /对话记录 查看历史。用 /use 切换到同一会话后可以接着追问。模型上下文使用最近 24 轮普通对话，旧版工具 Agent 的检查点历史不自动混入普通对话。

名称、重命名和删除

首条消息先生成简短临时名称，回复完成后使用模型概括的主题标题；手动名称不会被自动覆盖。左侧“重命名”修改当前会话名称，与 CLI /rename-session 名称 双向同步。

左侧“删除对话”先展示影响，再确认删除，与 CLI /delete-session、/delete-confirm 共用软删除机制。删除后两端列表都隐藏该会话，不能继续使用；历史审计不会物理清除。正在回复或存在未结束任务时，需先完成或取消后再删除。

创建第一个任务

  1. 点击“＋ 新建对话”，切换到“任务模式”。
  2. 直接描述目标，例如“搜索 machine learning 的公开资料，保存到工作目录的 research.md，再读回核对”。无需勾选工具。
  3. “最近提交”显示规划进度，点击“查看任务”查看每一步和结果证据。
  4. 搜索、工作目录内读取和新建文本默认自动执行。已有文件覆盖会暂停，点击“审批工具操作”，核对原内容及新内容后确认。
  5. Python 仍需“审阅并执行”，核对代码并输入 EXECUTE。

最多两项规划同时进行，每个计划最多 12 步。模型规划期限为 75 秒，单次自动执行进程最多 240 秒。失败或中断不自动重试；先核对结果再决定下一步。简单搜索可以直接在普通对话完成，不必创建任务。

技能偏好与工具目录

技能卡片可以展开阅读完整指导内容；超长内容在界面截断并提示。工具卡片显示说明、版本、风险类型、规划支持情况、输入和输出 Schema。

技能勾选后点击“保存挂载”才会生效。取消勾选并保存可移除手动偏好；系统仍会按任务需要选择适合的技能。配置按会话保存，刷新后保留，不影响其他会话。

每次提交保存一份当时的挂载快照。后续更改配置只影响新任务，不会改写已经生成的计划。技能内容不能授予权限，工具可用也不等于代码或路径授权。已有任务若不应继续，应通过暂停或取消操作处理。

输入指令

输入 / 可筛选指令，点击条目选择；也可打开“/ 指令说明”搜索用途。标有 GUI 的指令会切换视图或打开确认窗口，标有 CLI 的指令显示用法说明，不会偷偷运行终端命令。

执行、暂停、恢复和取消必须先在任务列表中选择明确的任务。/继续 只是打开代码预览，不能替代 EXECUTE。

查看状态与控制执行

  • 刷新页面只读取状态，不自动重发审批。
  • 任务详情每 3 秒同步，最近提交每 2 秒同步。
  • 暂停阻止后续步骤启动；在途步骤可能完成。
  • 恢复暂停不会启动工具，也不会自动授予权限。
  • 取消会发出持久取消请求；已有外部效果不保证可撤销。
  • 关闭页面不会取消已提交的工具执行。

同一提交标识重复发送会返回原提交记录。网络超时后先查看“最近提交”和任务列表，避免把同一目标主动作为新任务提交。

重规划和证据修复仍需 CLI 指令。新闻任务会基于已保存的来源生成摘要；其他任务仍查看工具结果。

待审批在哪里确认？

先点击“查看任务”或任务卡片。当前文件步骤显示“审批文件读取”，点击后核对工具和完整路径，再点击“确认审批文件读取”。Python 步骤点击“审阅并执行”，核对代码并输入 EXECUTE。确认后按既有权限继续低风险步骤；覆盖文件和执行代码仍会再次暂停。搜索与写入步骤使用“审批工具操作”。

左侧栏与权限管理

左侧提供新建对话、历史对话、技能管理、工具管理、工具与文件权限、指令说明。会话选择与新建对话也在左侧；中央保留任务输入、审批和结果。

“工具与文件权限”可选择“自动（限定范围）”“每步确认”或“禁用”，设置适用于当前数据目录的所有会话，包括 CLI。恢复策略不是无条件允许；未知工具、代码和文件仍受到原有策略约束。禁用会在调用网关处阻止工具，已经启动的调用无法撤回。

文件授权输入本机绝对路径，选择“仅一次读取”或“当前对话”，预览规范路径和范围后确认。文件夹授权包含子目录；仅允许读取。列表支持撤销授权，已使用的单次授权会标记。GUI 不新增持久跨会话授权，但可以查看和撤销 CLI 已创建的持久授权。任务中单次审批不留下持续文件授权。

审批后的步骤状态

提交确认后立即显示“已审批，准备执行”，认领并持有执行锁时显示“已审批／执行中”，完成后显示结果状态。CLI 的步骤状态使用同一个判定逻辑。若执行进程中断、认领仍在但执行锁已释放，显示“执行结果待核查”，不会退回待审批或自动重放。

自动工具与文件工作目录

“工具”面板是能力目录，不再要求勾选。规划器从受信任且未禁用的工具中按目标选择；技能会根据目标选择，也可保存个人偏好。旧版保存的工具勾选不再限制任务，请使用“工具与文件权限”禁用不需要的工具。

工作目录显示在权限面板，默认为所选数据目录下的 workspace。只有该目录内的文本、数据和静态文档可写入；不会自动覆盖已有文件。工作目录外读取仍需要路径授权，现有授权目录内的读取可以自动推进。代码永远不能设置成自动批准。

CLI 使用 /agent 目标 创建同类自动任务，/tool-approve 任务编号 审阅等待确认的步骤。/tool-modes 查看工作目录及策略，/tool-mode public_search ask 可把搜索改成每步确认。设置与 GUI 共用。

新闻请求

直接在普通对话输入“给我最新的AI新闻资讯，昨天的”或“给我最近的AI新闻资讯总结”即可获得检索结果和摘要，无需切换模式。任务模式也保留同类能力。普通对话的摘要直接出现在消息中；任务模式的摘要显示在任务详情。两者均包含北京时间范围、来源与发布时间。搜索失败、无匹配报道和摘要失败分别显示，不把百科搜索当成新闻搜索。

如何选择对话与任务

默认直接对话。系统根据当前请求和最近对话判断需要哪些能力，而不是仅按文字长短分流：

请求 处理方式
解释概念、写作、翻译、制定学习计划 在对话中回答，必要时澄清
最新 AI 新闻、昨天的新闻 对话内调用 news_search，返回北京时间范围和来源
搜索公开知识资料 对话内调用 public_search（Wikipedia，不是通用全网搜索）
基于刚才资料继续讨论 使用已有上下文，无需重复搜索
搜索后写文件、读回核对，或运行代码 显示任务建议和原因；点击“准备任务 · 确认后提交”填入目标，用户提交后才创建

普通对话每条最多执行一次公开搜索。搜索走与任务相同的 MCP 权限网关。若设为“每步确认”，会建议创建任务以审阅；禁用则说明无法检索，不会绕过限制。失败时明确告知，摘要失败时保留真实来源。模型分流可能误判，可补充需求或直接使用任务模式。

CLI 的 /chat 消息 和 /聊天 使用同一机制。遇到任务建议时会提供 /agent 目标 的创建方式；不会自动运行。搜索证据和任务建议与消息一起保存在本地会话记录。

黑灰界面与快捷操作

新版采用中性黑灰配色，保留 EduClaw 的书页标识与学习主题欢迎页。侧栏可收起，支持搜索历史对话；技能、工具、权限和指令使用独立窗口。窄屏采用抽屉式侧栏。

  • Enter 发送，Shift + Enter 换行；中文输入法选词不会触发发送。
  • 回复支持 Markdown 表格、列表、代码块、链接和复制；代码可单独复制。
  • 外部图片不自动加载，HTML 不执行，链接仅允许 HTTP、HTTPS 和邮件协议。
  • 管理窗口可用 Escape 关闭，并将键盘焦点返回入口按钮。
  • 欢迎页卡片填入示例目标，不会直接发送。

单次审批命令

侧栏“终端”可直接准备 Windows PowerShell 命令，无需模型规划：

  1. 新建或选择对话，打开“终端”。
  2. 填入现有本机工作目录的绝对路径、PowerShell 命令和 1–180 秒超时。
  3. 点击“准备命令并查看审批”。此时仅创建待审批任务，命令尚未执行。
  4. 在任务详情点击“审批工具操作”，核对规范化目录、完整命令和超时，输入 EXECUTE 再确认。
  5. 打开“结果证据”，查看退出码、标准输出、错误输出和耗时。刷新页面仍可查看保存的结果。

也可在任务模式直接描述“在 D:\projects\demo 运行终端命令 Get-ChildItem”，agent 会选择 run_terminal 并等待审批。普通对话遇到终端执行请求会提出任务建议；未给目录时先询问目录。

终端以当前本机用户权限运行，工作目录只是起始目录，不是文件隔离沙箱；命令可以访问本机用户本来有权限访问的资源。目录、命令和超时共同绑定审批，平衡模式下每次调用重新确认；文件读取授权不能代替终端审批。“权限与文件”中的 run_terminal 只提供“每步确认”和“禁用”。

当前是独立的非交互命令执行，不是持续的交互式终端：没有交互 stdin，不继承上一次的 cd 或变量，不运行常驻服务。Windows Job Object 管理本次创建的进程树，命令结束、超时或取消会清理该进程树，但已经写入的文件、网络请求等效果不会回滚。非零退出码或超时会停止任务并显示“需要核查”，不会自动重试。

每路输出最多保留 32 KiB；GUI 标记截断并最多展示每路 16000 字。直接输入密码、密钥会被保存在命令和审计记录中，因此请使用工具自身的本地凭据配置，不要把秘密写进命令文本。

持续终端与通用 Agent

侧栏“终端”默认打开持续终端面板。保留默认目录或自行填写现有目录，确认本机权限后打开。终端使用 Windows ConPTY 和 PowerShell，保留 cd、变量、环境及交互程序，支持文件读写、命令行工具、Git、构建测试、网络命令和长进程；并非限定为 DNS/TCP 等专用工具。

  • “直接输入”发送命令或交互回答，并附加回车；“停止 Agent / Ctrl+C”中断当前控制与程序。“关闭终端及子进程”结束整个进程树。
  • “交给 Agent 的目标”接受自然语言。Agent 每次观察真实输出，再决定输入、等待或结束。支持先运行测试、根据报错修改文件、再次运行验证。
  • 平衡模式默认逐次审阅 Agent 输入；可在打开时勾选“允许 Agent 连续控制此终端”。这是对当前终端的本机用户权限授权，不是仅允许某个目录的沙箱。Agent 提出敏感操作时仍暂停确认；模型判断不能保证识别所有风险。可随时撤销自动控制。
  • 工作目录填写的是初始位置；后续 cd 会改变当前目录。Agent 不应自动返回初始目录，位置不明确时查询 Get-Location。
  • GUI 和 CLI 使用同一个终端 ID，关闭窗口或重启 GUI 不会自动关闭终端；终端服务崩溃则标记中断，不恢复授权或重放输入。服务连续 30 分钟没有请求后退出并清理进程。每个工作空间最多 8 个活动终端。
  • 每轮 Agent 最多 30 次决策、约 15 分钟主动工作，等待人工审批不视为许可。达到预算后停止规划，终端保留，可提交后续目标。输出仅保留最近 128 Ki 字符，完整历史不作保证。

当前界面为文本输出和输入面板，不是完整的全屏终端模拟器；交互式编辑器的屏幕布局、鼠标和任意快捷键尚未提供。Agent 本轮结论来自模型判断，应结合实际测试和文件结果核实。单次审批命令仍可通过面板顶部切换使用。

对话审批模式

在侧栏“工具与文件权限”选择当前对话的审批模式。GUI 与 CLI 共用设置，重启保留，新对话默认平衡模式。

模式 自动执行范围
逐步确认（strict） 每次工具调用需要确认，持续终端 Agent 每次输入也确认
平衡模式（balanced，默认） 公开查询、已授权的文件读取、工作目录内新建文本文件自动执行；覆盖、代码与终端保留审批规则
自主执行（autonomous） 已启用并适配的工具自动执行，包括本机文件读取、工作目录文件覆盖、Python 与终端；不再逐步询问

启用自主执行前需明确确认：终端具有当前 Windows 用户权限，可读写或删除本机文件、联网、安装软件或修改系统；起始目录不是沙箱。它覆盖工具“每步确认”与终端单独的连续控制选项，不覆盖工具禁用、未知工具拒绝、参数校验和任务取消。文件写入专用工具仍限制工作目录和支持类型，通用终端则具有本机用户权限。

可随时切回平衡或逐步确认，后续调用会重新检查策略。已经开始的调用需用停止按钮中断；更改模式不会自动重放已有待审批操作。模式更改和按策略执行的任务步骤分别记录，不会伪装成人工逐步审批。已有文件覆盖仍校验内容摘要，防止覆盖预览后被其他程序修改的版本。

CLI：/autonomy 查看；/autonomy strict 或 /autonomy balanced 降级；/autonomy autonomous 后输入 AUTONOMOUS 明确授权。持续终端使用 /term，自动规划任务使用 /agent。自主模式下撤销整个对话的自动权限请使用 /autonomy balanced，而不是仅撤销某个终端的独立信任选项。
