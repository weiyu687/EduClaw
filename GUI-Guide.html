GUI 使用指南

创建第一个任务

  1. 点击“＋ 新会话”。新会话默认没有挂载技能和工具。
  2. 打开“工具”，勾选 run_python_code，点击“保存挂载”。
  3. 可选：打开“技能”，勾选 sandbox，保存挂载。
  4. 在文本框输入“使用 Python 计算 6*7 并输出结果”，点击“提交任务”。
  5. “最近提交”显示规划进度。规划完成后点击“查看任务”。
  6. 点击“审阅并执行”，核对实际 Python 代码，输入 EXECUTE 后确认。
  7. 在“结果证据”查看结果 42、状态和 SHA256 校验信息。

提交目标只创建待审批计划，不执行工具。最多两项规划可以同时进行。模型连接和规划期限为 75 秒；失败会显示状态，不自动重新提交。

挂载与卸载

技能卡片可以展开阅读完整指导内容；超长内容在界面截断并提示。工具卡片显示说明、版本、风险类型、规划支持情况、输入和输出 Schema。

勾选后点击“保存挂载”才会生效。取消勾选并保存就是卸载。配置按会话保存，刷新后保留，不影响其他会话。

每次提交保存一份当时的挂载快照。后续更改配置只影响新任务，不会改写已经生成的计划。技能内容不能授予权限，工具挂载也不等于代码或路径授权。已有任务若不应继续，应通过暂停或取消操作处理。

输入指令

输入 / 可筛选指令，点击条目选择；也可打开“/ 指令说明”搜索用途。标有 GUI 的指令会切换视图或打开确认窗口，标有 CLI 的指令显示用法说明，不会偷偷运行终端命令。

执行、暂停、恢复和取消必须先在任务列表中选择明确的任务。/继续 只是打开代码预览，不能替代 EXECUTE。

查看状态与控制执行

  • 刷新页面只读取状态，不自动重发审批。
  • 任务详情每 3 秒同步，最近提交每 2 秒同步。
  • 暂停阻止后续步骤启动；在途步骤可能完成。
  • 恢复暂停不会启动工具，也不会自动授予权限。
  • 取消会发出持久取消请求；已有外部效果不保证可撤销。
  • 关闭页面不会取消已提交的工具执行。

同一提交标识重复发送会返回原提交记录。网络超时后先查看“最近提交”和任务列表，避免把同一目标主动作为新任务提交。

文件读取、重规划和证据修复仍需 CLI 指令。GUI 尚不自动生成工具完成后的模型总结。
